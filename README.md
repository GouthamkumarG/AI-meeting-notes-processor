### 🤖 AI Meeting Notes Processor
> **Agentic pipeline with RAG & multi-tool orchestration**

Ingests unstructured meeting transcripts via webhook. Claude extracts action items, decisions, and owners with context from past meetings (RAG). Auto-creates Notion tasks and dispatches Gmail summaries — zero manual intervention.

**Architecture highlights:**
- 🧠 RAG via Supabase — past transcript retrieval
- ⚡ Claude Haiku — structured JSON extraction
- 🛡️ Error handling — IF node validates LLM output
- 📅 Dual triggers — webhook + daily schedule
